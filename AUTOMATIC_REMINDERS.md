# Автоматические напоминания в Google Calendar

## Обзор

Все создаваемые события в Google Calendar теперь автоматически получают напоминание за 15 минут до начала события. Это обеспечивает своевременное уведомление пользователей о предстоящих событиях.

## Техническая реализация

### 1. Формат напоминаний в Google Calendar API

```json
{
  "reminders": {
    "useDefault": false,
    "overrides": [
      {
        "method": "popup",
        "minutes": 15
      }
    ]
  }
}
```

### 2. Добавление напоминаний в код

#### EventParserService.validateAndConvertJson()

```java
// Всегда добавляем напоминание за 15 минут до события
JsonObject reminders = new JsonObject();
reminders.addProperty("useDefault", false);

// Создаем массив с напоминанием за 15 минут
com.google.gson.JsonArray overrides = new com.google.gson.JsonArray();
JsonObject reminder15min = new JsonObject();
reminder15min.addProperty("method", "popup");
reminder15min.addProperty("minutes", 15);
overrides.add(reminder15min);

reminders.add("overrides", overrides);
jsonObject.add("reminders", reminders);
```

### 3. Обновление промптов для GigaChat

#### Инструкции для GigaChat:
```text
ВАЖНО: Не добавляй поля attendees и reminders - они будут добавлены автоматически!
Напоминание за 15 минут до события добавляется для всех событий автоматически.
```

Это предотвращает дублирование или конфликты с напоминаниями, которые мог бы добавить GigaChat.

## Преимущества

### ✅ Консистентность
- Все события имеют одинаковое напоминание за 15 минут
- Нет необходимости настраивать напоминания вручную

### ✅ Удобство для пользователей
- Автоматическое напоминание за 15 минут до события
- Popup-уведомление в Google Calendar

### ✅ Простота реализации
- Добавляется на уровне backend автоматически
- Не зависит от интерпретации GigaChat

## Тестирование

### Примеры создаваемых событий:

1. **Текстовое сообщение:**
   ```
   Ввод: "Встреча завтра в 10:00"
   Результат в Calendar:
   - Событие: 10:00 - 11:00
   - Напоминание: за 15 минут (09:45)
   ```

2. **Голосовое сообщение:**
   ```
   Ввод: "Напоминание через 2 часа"
   Результат в Calendar:
   - Событие: текущее время + 2 часа
   - Напоминание: за 15 минут до события
   ```

## Влияние на существующие события

### ✅ Обратная совместимость
- Существующие события без напоминаний не затрагиваются
- Новые события автоматически получают напоминание

### ✅ Производительность
- Добавление напоминаний не влияет на производительность
- Минимальный overhead в JSON обработке
